Design Principles

✅ Per-Tenant Flexibility
Each tenant defines their own primary color, logo, font family, and content without code changes.
✅ Perceptual Color
OKLCH color space ensures stable hue across lightness levels and predictable contrast.
✅ Carbon v11 Integration
Design tokens map to Carbon's --cds-* CSS custom properties for runtime theme switching.
✅ Light/Dark Mode
Automatic via prefers-color-scheme or manual toggle. Neutral palette reverses in dark mode.
✅ Accessibility First
All text/background pairs meet WCAG AA contrast (4.5:1 for normal text, 3:1 for large text).
✅ Concentric Radius
outerRadius = innerRadius + padding for nested elements creates visual harmony.
